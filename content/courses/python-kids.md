Для дітей **10–14 років**, які готові до «справжнього» коду — після Scratch або з нуля.

Python — мова, якою користуються в науці, аналізі даних і штучному інтелекті, але вона достатньо проста для старту. Ми чергуємо **короткі пояснення й багато практики**, а кожен модуль завершуємо проєктом, який дитина може показати.
