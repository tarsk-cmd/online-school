# Сайт онлайн-школи «Дебют»

Сайт онлайн-школи для дітей 6–14 років і старшокласників: шахи, іноземні мови, математика, музика, IT, підготовка до НМТ і міжнародних сертифікатів.

- **Стек:** [Astro](https://astro.build) + [Tailwind CSS](https://tailwindcss.com) — статичний, швидкий сайт без сервера й бази даних.
- **Мови:** українська (основна), англійська й польська (ключові сторінки).
- **Хостинг:** GitHub Pages, публікація автоматична.
- **Адреса:** https://tarsk-cmd.github.io/online-school/

Увесь текст сайту лежить у папці **`content/`** у звичайних текстових файлах. Щоб додати курс, викладача чи статтю, **код змінювати не потрібно**.

> 📝 Список того, що треба заповнити реальними даними, — у файлі [`TODO-CONTENT.md`](TODO-CONTENT.md).
> Варіанти назви — у [`NAMING.md`](NAMING.md). План розвитку — у [`ROADMAP.md`](ROADMAP.md).

## Як усе влаштовано

```
content/                ← ВЕСЬ КОНТЕНТ (редагуйте тут)
  site.json             ← назва школи, контакти, месенджери, адреса форми
  home.json             ← кроки «Як проходить навчання» і переваги
  faq.json              ← часті запитання (головна)
  reviews.json          ← відгуки
  pricing.json          ← ціни, пакети, знижки
  directions/*.json     ← напрями (шахи, мови, математика…)
  courses/*.md          ← курси (одна сторінка = один файл)
  teachers/*.json       ← викладачі
  blog/*.md             ← статті
  pages/*.md            ← тексти сторінок: для батьків, репетиторство, іспити, політика, умови
public/                 ← картинки, фото викладачів, favicon
src/                    ← код сайту (зазвичай редагувати не потрібно)
  i18n/ui.ts            ← переклади меню, кнопок і підписів
```

Файли бувають двох типів:

- **`.json`** — дані у форматі `"поле": "значення"`. Обов’язково зберігайте лапки, коми між рядками і дужки. Якщо помилитеся — сайт не збереться, а GitHub покаже, у якому файлі помилка (сайт при цьому не зламається — лишиться попередня версія).
- **`.md`** (Markdown) — текст із простим форматуванням. Зверху між рядками `---` — службові поля (назва, вік тощо), нижче — звичайний текст. `## Заголовок`, `**жирний**`, `- пункт списку`, `[текст посилання](/contacts/)`.

## Як редагувати сайт без програм (через GitHub)

Найпростіший спосіб — прямо в браузері:

1. Відкрийте репозиторій на GitHub → папку `content/` → потрібний файл.
2. Натисніть іконку олівця ✏️ (**Edit this file**).
3. Змініть текст.
4. Натисніть **Commit changes…** → напишіть коротко, що змінили (наприклад, «Оновив ціни») → **Commit changes**.
5. Через 1–3 хвилини зміни з’являться на сайті. Перебіг публікації видно у вкладці **Actions** (зелена галочка — усе гаразд, червоний хрестик — помилка у файлі; відкрийте його, щоб побачити, де саме).

**Новий файл:** у потрібній папці натисніть **Add file → Create new file**. Найпростіше — відкрити схожий наявний файл, скопіювати його вміст і змінити.

**Завантажити фото:** відкрийте папку `public/images/teachers/` (якщо її немає — створіть, додавши будь-який файл) → **Add file → Upload files**.

> 💡 Назви файлів пишіть **латиницею, маленькими літерами, через дефіс**: `chess-kids.md`, `olena-kovalenko.json`. Назва файлу стає адресою сторінки: `courses/chess-kids.md` → `/courses/chess-kids/`.

## Підключити форму заявок

Сайт не має власного сервера, тому заявки приймає безкоштовний сервіс. Є два варіанти.

### Варіант А: Formspree (рекомендовано — форма прямо на сайті)

1. Зареєструйтеся на [formspree.io](https://formspree.io) (безкоштовний тариф — 50 заявок на місяць).
2. **New Form** → назва «Пробний урок» → вкажіть email, куди надходитимуть заявки.
3. Скопіюйте адресу форми виду `https://formspree.io/f/abcdwxyz`.
4. У `content/site.json` вставте її в `form.endpoint`, а `form.mode` залиште `"formspree"`.
5. Відправте тестову заявку з сайту й підтвердьте email у листі від Formspree.

Заявка містить: ім’я батька/матері, вік дитини, напрям, зручний месенджер, телефон, коментар, мову сайту і сторінку, з якої її надіслали.

### Варіант Б: Google Forms

1. Створіть форму в [Google Forms](https://forms.google.com) з потрібними полями.
2. **Надіслати → посилання** → скопіюйте посилання.
3. У `content/site.json`: `"mode": "google"`, `"googleFormUrl": "ваше посилання"`.

Замість форми на сайті з’явиться кнопка «Відкрити анкету». Кнопки месенджерів показуються в обох варіантах.

## Додати викладача

1. Відкрийте папку `content/teachers/` і скопіюйте вміст будь-якого файлу.
2. Створіть новий файл, наприклад `content/teachers/olena-kovalenko.json`:

```json
{
  "name": "Олена Коваленко",
  "role": "Викладачка англійської мови",
  "order": 7,
  "directions": ["languages", "exams"],
  "subjects": ["Англійська для дітей", "IELTS"],
  "experience": "8 років викладання",
  "bio": "Кілька речень про викладача: підхід, досвід, що любить.",
  "education": "КНУ ім. Шевченка, філологія; CELTA",
  "teachingLanguages": ["українська", "англійська"],
  "photo": "/images/teachers/olena-kovalenko.jpg"
}
```

- `directions` — напрями, на сторінках яких показувати викладача: `chess`, `languages`, `math`, `music`, `it`, `exams` (це назви файлів у `content/directions/`).
- `order` — порядок на сторінці «Викладачі» (менше число — вище).
- `photo` — необов’язково. Без фото показується кольорова заглушка з ініціалами. Фото — квадратне або 4:3, до 300 КБ, у `public/images/teachers/`.
- `"founder": true` — додає позначку «Засновник школи».

3. Щоб викладач з’явився на сторінці курсу — додайте назву його файлу (без `.json`) у поле `teachers` курсу: `teachers: ["olena-kovalenko"]`.

## Додати курс

1. Скопіюйте наявний курс, наприклад `content/courses/english-kids.md`, у новий файл `content/courses/spanish-kids.md`.
2. Змініть поля зверху (між `---`):

| Поле | Що означає | Допустимі значення |
|---|---|---|
| `title` | Назва курсу | текст |
| `direction` | Напрям | `chess`, `languages`, `math`, `music`, `it`, `exams` або ваш новий |
| `summary` | Короткий опис для картки (1–2 речення) | текст |
| `order` | Порядок усередині напряму | число |
| `ages` | Вікові групи для фільтра | `"6-8"`, `"9-11"`, `"12-14"`, `"15-17"` |
| `ageLabel` | Як показати вік | `"7–12 років"` |
| `formats` | Формат | `"group"`, `"individual"` |
| `levels` | Рівень | `"zero"` (з нуля), `"continue"` (продовжую) |
| `groupSize` | Розмір групи (необов’язково) | `"4–6 дітей"` |
| `lessonDuration`, `courseDuration` | Тривалість | текст |
| `scheduleExample` | Приклад розкладу | список рядків |
| `price` | `group` і/або `individual` | `"450 грн / заняття"` |
| `tools` | Платформи | список |
| `teachers` | Викладачі | назви файлів із `content/teachers/` |
| `outcomes` | Що дитина вмітиме | список |
| `modules` | Програма: `title`, `lessons`, `topics` | див. приклад |
| `homework` | Домашні завдання (необов’язково) | текст |
| `faq` | Питання про курс: `q`, `a` | список |
| `translations` | Назва й опис англ./польською для каталогу | необов’язково |
| `draft: true` | Сховати курс, поки він не готовий | |

3. Під другим `---` напишіть опис курсу звичайним текстом («Для кого курс»). Заголовки всередині опису — через `###`.
4. Збережіть. Курс автоматично з’явиться в каталозі з фільтрами, на сторінці напряму й отримає власну сторінку.

> ⚠ Відступи у списках (`modules`, `faq`) мають значення: використовуйте пробіли (не Tab), як у прикладі.

## Додати новий предмет (напрям)

Наприклад, «Малювання»:

1. Скопіюйте `content/directions/music.json` у `content/directions/art.json`.
2. Змініть поля:
   - `title`, `short` — назва та короткий опис трьома мовами (`en`, `pl` можна прибрати — тоді покажеться українська);
   - `description`, `highlights`, `subjects` — текст сторінки напряму;
   - `order` — місце серед напрямів;
   - `icon` — одна з іконок: `chess`, `languages`, `math`, `music`, `it`, `exams`;
   - `color` — колір: `indigo`, `teal`, `violet`, `rose`, `emerald`, `amber`.
3. Створіть хоча б один курс з `direction: art` (див. вище).

Напрям автоматично з’явиться на головній, у фільтрах каталогу, у формі заявки й отримає сторінку `/directions/art/`.

> Потрібна нова іконка? Попросіть розробника додати її в `src/components/Icon.astro` і в список `icon` у `src/content.config.ts` (5 хвилин роботи).

## Шаховий тренажер

Безкоштовний інтерактивний тренажер для дітей 7–12 років: **`/trener/`** (пункт «Тренажер» у меню і блок-запрошення на головній). Без реєстрації, реклами й сервера: бали, зірки й нагороди зберігаються в браузері дитини (`localStorage`; якщо він недоступний — тренажер працює, просто без збереження).

**Режими** (відкриваються по черзі; у блоці «Для батьків і вчителів» унизу сторінки можна відкрити всі рівні або скинути прогрес):

1. **Як ходять фігури** — тура, слон, ферзь, король, кінь, пішак: «збери всі зірочки» за мінімум ходів, далі з перешкодами й небезпечними полями.
2. **Шах чи не шах?** — відповісти Так/Ні і показати фігуру, що дає шах.
3. **Втечі від шаху** — зараховується будь-який хід, що рятує короля.
4. **Мат в 1 хід** — легкі / середні / складніші; зараховується будь-який матуючий хід.

### Де що лежить

```
src/data/puzzles/        ← ЗАДАЧІ (редагуйте тут)
  pieces.json            ← режим 1: рівні-фігури та завдання «зірочки»
  check.json             ← режим 2: «Шах чи не шах?»
  escape.json            ← режим 3: «Втечі від шаху»
  mate.json              ← режим 4: «Мат в 1 хід»
src/components/trainer/  ← код тренажера (окремо від решти сайту)
  i18n/uk.ts             ← усі тексти інтерфейсу й репліки помічника Пішка
  engine/pieces.mjs      ← правила режиму 1 (спільні для гри й перевірки)
scripts/check-puzzles.mjs← перевірка всіх задач
src/pages/trener/        ← сторінки /trener/ і /trener/embed/
```

### Як додати задачу

Відкрийте потрібний файл і додайте новий запис у список `puzzles` (не забудьте кому між записами). FEN позиції зручно скопіювати з lichess.org → «Дошка-редактор» → поле FEN.

**Мат в 1** (`mate.json`):

```json
{ "id": "m33", "difficulty": "medium",
  "fen": "6k1/5ppp/8/8/8/8/5PPP/R5K1 w - - 0 1", "toMove": "w",
  "solution": "Ra8#",
  "hint": { "uk": "Королю заважають власні пішаки." },
  "explanation": { "uk": "Мат на останній горизонталі." } }
```

- `id` — унікальний; `difficulty` — `easy`, `medium` або `hard` (підрівень).
- `toMove` — чия черга: `w` (білі) або `b` (чорні), має збігатися з FEN. Якщо ходять чорні — дошка автоматично перевертається.
- `solution` — ваш розв’язок у шаховій нотації (SAN). Дитині зараховується **будь-який** мат, а не лише цей.
- `hint` — текст підказки (кнопка «Підказка» ще й підсвічує фігуру, якою треба ходити); `explanation` — пояснення після розв’язання.
- Необов’язково: `"tags": ["smothered"]` — задача на задушений мат (дає нагороду «Задушений мат»).

**Шах чи не шах?** (`check.json`) — те саме, але замість `solution` поле `"check": true` або `false` (чи під шахом король сторони, що ходить). Фігуру, яка дає шах, програма знаходить сама.

**Втечі від шаху** (`escape.json`) — сторона, що ходить, має бути під шахом; `solution` — один із правильних ходів (для підказки), зараховується будь-який легальний.

**Як ходять фігури** (`pieces.json`) — у рівні фігури додайте завдання в `tasks`:

```json
{ "start": "b2", "stars": ["b8", "h8"], "blockers": ["a4"], "enemies": ["nd5"],
  "hint": { "uk": "Не ставай на поля, які б’є чорний кінь." } }
```

`start` — звідки стартує фігура, `stars` — зірочки, `blockers` — свої пішаки-перешкоди, `enemies` — чорні «сторожі» (літера фігури + поле: `n` кінь, `b` слон, `r` тура, `q` ферзь, `p` пішак), поля, які вони б’ють, стають небезпечними. Для пішака є ще `food` — чорні пішаки, яких можна з’їсти. Мінімальну кількість ходів (для зірок) програма рахує сама.

Рівні в режимах 2–4 формуються автоматично: задачі діляться на частини по 5–7 штук.

### Перевірка задач

```bash
npm run check-puzzles
```

Скрипт через chess.js перевіряє кожну задачу: FEN коректний, по одному королю, реалістична кількість фігур, сторона, що не ходить, не під шахом; у «мат в 1» існує матуючий хід і ваш `solution` — справді мат; у «втечах» король під шахом і є легальні ходи; у «шах чи не шах» відповідь правильна; у режимі 1 зірочки досяжні й не стоять на небезпечних полях. З `--verbose` показує всі матуючі ходи й рятівні ходи кожної задачі.

Перевірка запускається автоматично перед кожною збіркою (`npm run build`) і в GitHub Actions — **помилкова задача зупинить публікацію**, а сайт лишиться в попередній версії. Текст помилки покаже файл і `id` задачі.

### Вбудувати тренажер на інший сайт (iframe)

Є окрема версія без шапки й футера: **https://tarsk-cmd.github.io/online-school/trener/embed/** (посилання «Записатися на пробний урок» відкриваються в новій вкладці на сайті школи).

```html
<iframe
  src="https://tarsk-cmd.github.io/online-school/trener/embed/"
  title="Шаховий тренажер онлайн-школи «Дебют»"
  style="width:100%;max-width:1100px;height:900px;border:0;border-radius:16px"
  loading="lazy"
  allow="autoplay"
></iframe>
```

Щоб висота iframe підлаштовувалася під вміст (необов’язково), додайте після нього:

```html
<script>
  window.addEventListener('message', function (e) {
    if (e.data && e.data.type === 'debut-trainer:height') {
      document.querySelectorAll('iframe[src*="/trener/embed/"]').forEach(function (f) {
        f.style.height = e.data.height + 'px';
      });
    }
  });
</script>
```

Якщо підключите власний домен, замініть адресу в `src`.

### Переклад тренажера

Тексти інтерфейсу — `src/components/trainer/i18n/uk.ts`. Для польської чи англійської скопіюйте файл (`pl.ts`), перекладіть значення й додайте мову в `src/components/trainer/i18n/index.ts`. Тексти задач (`hint`, `explanation`, `title`, `intro`) у JSON мають вигляд `{ "uk": "…" }` — допишіть поряд `"pl": "…"`. Потім створіть сторінку `src/pages/pl/trener/index.astro` з `<Trainer lang="pl" />`.

## Публікація на GitHub Pages

Сайт публікується автоматично (файл `.github/workflows/deploy.yml`) після кожної зміни в гілці **`main`**.

**Один раз увімкніть Pages:**

1. Репозиторій → **Settings** → **Pages**.
2. У **Build and deployment → Source** оберіть **GitHub Actions**.
3. Злийте зміни в `main` (або у вкладці **Actions** → «Deploy to GitHub Pages» → **Run workflow**).
4. Через 1–3 хвилини сайт буде доступний за адресою `https://<власник>.github.io/<назва-репозиторію>/` — зараз це https://tarsk-cmd.github.io/online-school/

Адреса й base path визначаються з назви репозиторію автоматично, тому після перейменування репозиторію нічого міняти не треба.

### Власний домен

1. **Settings → Pages → Custom domain** — вкажіть домен (наприклад, `debut.school`) і налаштуйте DNS за [інструкцією GitHub](https://docs.github.com/pages/configuring-a-custom-domain-for-your-github-pages-site).
2. У `.github/workflows/deploy.yml` замініть:
   ```yaml
   SITE_URL: https://debut.school
   BASE_PATH: /
   ```

## Запуск на своєму комп’ютері (для розробника)

Потрібен [Node.js](https://nodejs.org) версії 22.23 або новішої.

```bash
npm install
```

```bash
npm run dev
```

Сайт відкриється на http://localhost:4321/online-school/ і оновлюватиметься при кожній зміні файлів.

Інші команди:

| Команда | Що робить |
|---|---|
| `npm run build` | Збирає готовий сайт у папку `dist/` |
| `npm run preview` | Показує зібраний сайт локально |
| `npm run check:links` | Перевіряє биті внутрішні посилання (після `build`) |
| `npm run check-puzzles` | Перевіряє шахові задачі тренажера (також запускається в `build`) |
| `npx astro check` | Перевіряє типи й помилки в коді |

### Для розробника: архітектура

- `src/content.config.ts` — схеми контенту (валідація полів у `content/`).
- `src/views/` — сторінки, спільні для всіх мов (головна, каталог, ціни, контакти).
- `src/pages/` — маршрути: українські в корені, `[lang]/` — англійські й польські; `[lang]/[page].astro` — заглушки неперекладених сторінок.
- `src/i18n/routes.ts` — base path, локалізовані посилання, логіка перемикача мов.
- `src/components/` — UI-компоненти; `Icon.astro` — SVG-іконки.
- `src/styles/global.css` — палітра (Tailwind `@theme`) і базові стилі.
- Шрифти Rubik і Inter (Google Fonts, з кирилицею) підключені локально через Fontsource — без запитів до Google, що швидше й краще для приватності.
