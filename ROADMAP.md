# План розвитку: від сайту до повноцінної онлайн-школи

> Це **лише план**. Нічого з описаного нижче ще не реалізовано.
> Оцінки складності орієнтовні: **S** — до 1 тижня, **M** — 2–4 тижні, **L** — 1–2 місяці, **XL** — 3+ місяці (для 1 розробника).

## Загальний принцип

Не будувати все одразу. Кожен етап має **окремо приносити користь** школі, а рішення «купити готове» майже завжди краще за «написати своє», доки школа маленька. Власний код варто писати там, де є унікальна цінність (шахова частина, звіти для батьків), а не там, де є добрі готові сервіси (оплата, відеозв’язок, CRM).

## Рекомендована цільова архітектура

```
Сайт (Astro, поточний) ──► Застосунок (кабінети, розклад, LMS)
                                │
              ┌─────────────────┼───────────────────┐
         База даних +       Оплати            Інтеграції
         авторизація       (LiqPay /         (Lichess API, Zoom API,
         (Supabase /        Monobank /        Google Calendar,
         PostgreSQL)        Stripe)           Telegram-бот)
```

- **Фронтенд застосунку:** Astro (поточний сайт) + острівці на React/Svelte, або окремий застосунок на **Next.js / SvelteKit**.
- **Бекенд:** **Supabase** (PostgreSQL + авторизація + сховище файлів + Row Level Security) — дає 80% потрібного без власного сервера. Альтернатива — Node.js (NestJS/Fastify) + PostgreSQL на Railway / Fly.io / Hetzner, якщо потрібен повний контроль.
- **Хостинг:** Vercel / Netlify / Cloudflare Pages для фронтенду; Supabase Cloud у регіоні ЄС (Франкфурт) для даних — важливо для GDPR.

---

## Етап 0. Підготовка (зараз, паралельно з запуском сайту)

**Що:** аналітика без cookie, базові процеси.

- Plausible / Umami (приватна аналітика без банера cookie) або Cloudflare Web Analytics.
- Telegram-бот для сповіщень про нові заявки (через Formspree webhook → Make/Zapier або простий Cloudflare Worker).
- Таблиця заявок і учнів у Google Sheets / Notion — щоб зрозуміти реальні процеси до автоматизації.

**Складність:** S. **Що першим:** аналітика + сповіщення про заявки в Telegram.

---

## Етап 1. CRM для заявок

**Що:** усі заявки в одному місці, статуси (нова → пробний урок → навчається → відмова), нагадування, історія спілкування.

**Рекомендація:** спершу **готова CRM** — KeyCRM, Bitrix24 (безкоштовний тариф), HubSpot Free, Pipedrive. Форма сайту надсилає заявки в CRM через webhook (Formspree → CRM або напряму в API CRM через Cloudflare Worker).

**Власна CRM** має сенс лише разом з етапом 2 (кабінетами), коли учні вже зберігаються у власній базі.

**Складність:** S (готова CRM) / M (власна). **Що першим:** обрати CRM, налаштувати воронку і webhook з форми.

---

## Етап 2. Особисті кабінети учнів і батьків

**Що:**
- Батьки: діти, розклад, абонементи й залишок занять, звіти викладачів, оплати.
- Учні: розклад, посилання на заняття, домашні завдання, прогрес.
- Викладачі: свої групи, журнал відвідування, звіти.
- Адміністратор: учні, групи, викладачі.

**Стек:** Supabase Auth (вхід через email-посилання / Google / телефон), PostgreSQL з Row Level Security (батьки бачать лише своїх дітей), фронтенд на Next.js або SvelteKit.

**Важливо:** діти до 14 років — акаунт створюють і контролюють батьки; мінімум персональних даних дітей; згоди на обробку даних; оновлена політика конфіденційності.

**Складність:** L. **Що першим:** модель даних (Сім’я → Діти → Записи на курси → Групи → Заняття) і вхід для батьків з переглядом розкладу та звітів.

---

## Етап 3. Розклад і бронювання

**Що:** календар занять, запис на пробний урок у вільний слот, перенесення індивідуальних занять за правилами школи, нагадування.

**Рекомендація:**
- Пробні уроки на старті — **Cal.com** (open source, можна self-host) або Calendly: вбудовується на сайт за години.
- Далі — власний розклад у базі (групи з постійним розкладом + індивідуальні слоти викладачів), синхронізація з **Google Calendar** викладачів.
- Нагадування — Telegram-бот / email (Resend, Postmark) / Viber Business Messages.
- Часові пояси: зберігати все в UTC, показувати в часовому поясі сім’ї.

**Складність:** M (Cal.com) / L (власне). **Що першим:** Cal.com для пробних уроків прямо на сайті.

---

## Етап 4. Онлайн-оплата

**Що:** оплата разових занять і абонементів, автоматичне нарахування занять на баланс, сімейні знижки, чеки.

**Стек:**
- Україна: **LiqPay**, **WayForPay**, **Monobank Acquiring (plata by mono)**, Fondy.
- Для сімей за кордоном: **Stripe** (потрібна юрособа в країні, яку підтримує Stripe) або WayForPay з оплатою в EUR.
- Фіскалізація: ПРРО (Checkbox, Вчасно.Каса) — уточнити з бухгалтером вимоги для ФОП.
- Webhook платіжної системи → нарахування занять у базі.

**Складність:** M. **Що першим:** платіжні посилання (invoice links) з CRM, без інтеграції з кабінетом; повна інтеграція — після етапу 2.

---

## Етап 5. LMS: домашні завдання, прогрес, сертифікати

**Що:**
- Домашні завдання: видача, здача (текст, файл, фото, аудіо для музики), перевірка з коментарем.
- Прогрес: карта навичок за модулями курсу, звіти для батьків, графіки.
- Сертифікати про завершення курсу (PDF з унікальним номером і сторінкою перевірки).

**Варіанти:**
- **Готова LMS:** Moodle (безкоштовна, важка), Google Classroom (безкоштовно, просто), або платформи на кшталт LearnWorlds/Teachable (платні).
- **Власна LMS** поверх кабінетів (етап 2) — краща інтеграція і досвід для батьків, але більше роботи.

**Стек (власна):** таблиці в Supabase (`assignments`, `submissions`, `skills`, `progress`), Supabase Storage для файлів, генерація PDF (react-pdf / Puppeteer / сервіс на кшталт DocRaptor).

**Складність:** L–XL. **Що першим:** звіти викладачів для батьків після модуля (найцінніше для батьків) — навіть простим шаблоном у кабінеті; потім домашні завдання.

---

## Етап 6. Інтеграція з Lichess

**Що:** автоматичне відстеження шахового прогресу учнів.

- **Lichess API** (безкоштовне, відкрите): рейтинги учнів, партії, результати задач, турніри команди.
- OAuth-вхід через Lichess (учень прив’язує свій акаунт).
- Автоматичне створення **Lichess Studies** з домашніми завданнями й перевірка, які розділи відкривав учень.
- Внутрішні турніри школи (Arena/Swiss) через API, таблиця результатів у кабінеті.
- Графік рейтингу й статистика помилок для звіту батькам.

**Важливо:** дотримуватися правил використання Lichess API і лімітів запитів; Kid mode для дитячих акаунтів.

**Складність:** M. **Що першим:** показ рейтингу й останніх партій учня в кабінеті + автоматичні турніри команди. Це сильна унікальна перевага флагманського напряму — варто робити одразу після етапу 2.

---

## Етап 7. Zoom / Google Meet

**Що:** автоматичні посилання на заняття, присутність, без ручного розсилання.

- **Zoom API** (Server-to-Server OAuth): створення зустрічей для кожного заняття групи, посилання в кабінеті й нагадуванні, звіт присутності.
- **Google Meet** через Google Calendar API — простіший варіант, якщо школа на Google Workspace (для освіти є пільгові тарифи).
- Альтернатива з відкритим кодом — **Jitsi** / **BigBlueButton** (self-host, повний контроль даних).

**Складність:** M. **Що першим:** постійні посилання на кожну групу (вручну), потім автоматизація через API разом з розкладом.

---

## Етап 8. Мобільний застосунок

**Що:** розклад, сповіщення, домашні завдання, оплата, чат з викладачем.

**Рекомендація:** спершу **PWA** (встановлюваний веб-застосунок з push-сповіщеннями) на базі кабінетів — це майже безкоштовно після етапу 2. Нативний застосунок — лише якщо PWA не вистачає.

**Стек нативного:** React Native + Expo (спільна логіка з веб-версією на React) або Flutter. Backend — той самий Supabase.

**Складність:** M (PWA) / XL (нативний). **Що першим:** PWA + Telegram-бот для сповіщень (батьки в Україні активно користуються Telegram).

## Що варто врахувати з самого початку

- **Дані дітей і GDPR:** зберігання в ЄС, мінімум даних, згоди батьків, право на видалення, журнали доступу.
- **Резервні копії** бази даних і план відновлення.
- **Ролі й доступи:** адміністратор, викладач, батьки, учень — з першого дня.
- **Мультимовність** застосунку (uk/en/pl) — закладати у структуру, як на сайті.
- **Сайт лишається статичним:** маркетингові сторінки на Astro швидкі й дешеві; застосунок — окремо, наприклад на `app.назва-школи.ua`.
