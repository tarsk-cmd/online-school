# Що потрібно заповнити

На сайті всі місця, де потрібні реальні дані, позначені **`[ЗАПОВНИТИ]`** (в англійських/польських текстах — `[TODO]`). Нічого з цього не вигадано — замініть на справжні факти або видаліть.

Швидко знайти всі заглушки:

```bash
grep -rn "ЗАПОВНИТИ\|\[TODO" content
```

Позначайте виконане: `- [ ]` → `- [x]`.

## 1. Головне (обов’язково до запуску)

**`content/site.json`**
- [ ] Остаточна назва школи і слоган (див. `NAMING.md`)
- [ ] Email (`contacts.email`)
- [ ] Телефон (`contacts.phone` — як показувати, `contacts.phoneHref` — лише цифри з +)
- [ ] Години роботи
- [ ] Telegram — `https://t.me/ваш_username`
- [ ] Viber — `viber://chat?number=%2B380XXXXXXXXX` (номер без +, замість + пишемо `%2B`)
- [ ] WhatsApp — `https://wa.me/380XXXXXXXXX`
- [ ] Адреса форми Formspree (`form.endpoint`) або Google Form (`form.mode: "google"` + `form.googleFormUrl`)
- [ ] Команда школи на Lichess (`social.lichessTeam`) і, за бажанням, Instagram / Facebook / YouTube
- [ ] Юридичні дані: ФОП / юрособа, ІПН / ЄДРПОУ, адреса (`legal`)

## 2. Ціни — `content/pricing.json`
- [ ] Ціни разового заняття: група / індивідуально
- [ ] Ціни абонементів на 4 і 8 занять: група / індивідуально
- [ ] Відсоток сімейної знижки (2+ дітей)
- [ ] Відсоток знижки за 2+ предмети
- [ ] За скільки годин можна перенести індивідуальне заняття
- [ ] Ціни на підготовку до іспитів
- [ ] Умови повернення коштів
- [ ] Чи можлива оплата в EUR / PLN
- [ ] Способи оплати (також у `content/faq.json` → «Як оплачувати?»)

Ціни на сторінках курсів: поле `price` у кожному файлі `content/courses/*.md` (17 файлів, з них 5 приховано через `draft: true`).

## 3. Викладачі — `content/teachers/*.json`
Для кожного з 6 викладачів:
- [ ] Ім’я та прізвище
- [ ] Досвід (років)
- [ ] Біографія: реальні досягнення, сертифікати, звання
- [ ] Освіта
- [ ] Фото (покладіть у `public/images/teachers/` і вкажіть шлях у полі `photo`)

Особливо **засновник** (`founder-chess.json`): шаховий розряд/звання, тренерська категорія, досягнення учнів, де тренує офлайн, мови.

Також:
- [ ] Викладачі скрипки й гітари (згадано в `content/courses/piano.md`)
- [ ] Як ви перевіряєте викладачів (`content/pages/parents.md` → «Безпека дітей онлайн»)

## 4. Відгуки — `content/reviews.json`
- [ ] Замінити 3 заглушки на **реальні** відгуки батьків (зі згодою на публікацію). Поки відгуків немає — краще видалити блок, ніж публікувати вигадані.

- [ ] Перевірити розмір груп і тривалість занять

### 5.1. Нові короткі курси (детальні програми по заняттях)

`english-beginners-7-10.md`, `polish-from-zero-8-12.md`, `math-logic-7-9.md`, `piano-beginners-6-10.md`, `scratch-programming-8-12.md`

Спільне для всіх п’яти:
- [ ] Ціни (`price`)
- [ ] Викладачі (`teachers: []` — вкажіть id з `content/teachers/`, напр. `teacher-english`)
- [ ] Частота занять: 1 чи 2 рази на тиждень (`courseDuration` і розділ «Формат» у тексті)

Окремо по курсах:
- [ ] Англійська: де вчитель надсилає роздруківки й домашні завдання
- [ ] Польська: де вчитель надсилає матеріали; чи є конкретний підручник
- [ ] Математика: вступна діагностика — безкоштовна чи платна, як записатися; назва онлайн-дошки
- [ ] Фортепіано: наступний курс після цього; п’єса для лівої руки на занятті 7; нотний посібник
- [ ] Scratch: тема листівки на занятті 4; наступний курс; чи є технічна консультація перед стартом

Варто вирішити:
- [x] Старі курси `english-kids`, `polish-kids`, `math-school`, `piano`, `scratch` приховано (`draft: true`), їх замінили нові. Щоб повернути курс на сайт, видаліть у ньому рядок `draft: true`.
